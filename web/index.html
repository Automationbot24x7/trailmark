How Trailmark works

  1. The books become a graph. Thirteen sample ledgers (purchase orders, goods receipts, invoices, payments, bank statement lines, our GSTR-2B) are linked by the keys an accountant uses: PO number, bank reference (UTR), GSTIN and invoice number. 184 nodes, 265 relationships.
  2. Six checks walk each trail. Every check is a plain Cypher file. A dashed red link is one the trail expects but cannot find; an amber one is a fix the graph can see; a green one is a fix you made.
  3. It runs in this tab. Relate, compiled to WebAssembly, rebuilds the graph from store/trailmark.rl and runs the same Cypher the command line and the AI-agent server run. There is no server: what you do here stays in your browser.
